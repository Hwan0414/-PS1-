# -테일즈 오브 판타지아(PS1) 한글 패치-

테일즈 오브 판타지아(PS1) 한글 패치입니다.

## 개요
이 패치는 AI(기계 번역)를 사용해 번역한 후, 사람이 직접 검수하여 만든 한글화 파일입니다. 패치 과정은 Xdeita를 사용하여 게임의 BIN 파일에 적용합니다.

## 설치 방법 (간단)
1. 패치 파일(또는 패치 도구)과 원본 BIN 파일을 준비합니다.  
2. Xdeita를 실행합니다.  
3. Xdeita에서 원본 BIN 파일을 열고, 제공된 패치 파일을 적용합니다.  
4. 패치가 완료된 BIN을 저장하여 게임에서 사용합니다.

(※ 사용하시는 환경이나 Xdeita 버전에 따라 세부 과정이 다를 수 있으니, 필요한 경우 자세한 절차를 추가로 안내해 드립니다.)

## 주의 사항
- 번역은 AI를 사용해 수행했고, 이후 검수를 거쳤지만 오역이나 어색한 표현이 남아 있을 수 있습니다.  
- 개인적/비상업적 용도로만 사용해 주세요. 원저작권은 해당 게임 제작사에 있습니다.

## 오역/오류 보고
거슬리는 번역이나 오류를 발견하시면 스크린샷과 함께 GitHub 이슈를 올려 주세요. 확인 후 가능하면 수정하겠습니다.

## 기여
기여를 원하시면 이슈나 풀 리퀘스트로 제안해 주세요. 번역 수정, 표현 개선, 패치 적용 방법 개선 모두 환영합니다.
